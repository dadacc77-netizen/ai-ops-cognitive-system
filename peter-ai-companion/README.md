# Peter AI Companion｜雙模式語音陪跑 V1.0 RC1

這是一套可交給 Codex 執行、測試與持續擴充的語音優先陪跑系統封裝。

## 正式定位

- 系統名稱：`Peter AI Companion｜雙模式語音陪跑`
- 互動層雙模式：
  1. `語音陪跑模式`：預設。Peter 可用長段語音自然說完，系統整理目標、重點、待辦、檔案與下一步。
  2. `安靜慢慢來模式`：低壓、一次一件事、短回覆、不堆大量教學。
- 執行層雙模式：
  1. `Mode A｜企劃討論`：預設，只做整理、腳本、分鏡、Prompt、成本與規劃。
  2. `Mode B｜正式生成`：只有精確觸發詞 `【正式生成影片】` 且三道門全部通過後才可進入。

> 互動層與執行層是兩個不同維度，不得混用。

## 核心能力

- 長語音輸入整理
- 圖片、影片、PDF、Excel、PPT、Word 與一般文件的雲端整理意圖辨識
- 每日結束時的報表、資料夾、命名與版本整理
- 權限預設私人；主管／supervisor 權限必須由 Peter 明確授權
- 程式、流程或系統問題可標記為 Codex 後台處理候選
- 涉及密碼、API 金鑰、私鑰時啟動 Safety Stop
- 不宣稱固定 24 小時支援

## 執行測試

```bash
python tools/run_all.py
```

本封裝不含 Peter 的私人對話、真實公司資料、帳密、API 金鑰、雲端連結或未公開商業內容。
